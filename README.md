# Shadow_Core_Defense
라운드 기반 전투에서 플레이어 생존과 코어 방어를 동시에 요구하는 게임입니다.   보스 패턴과 시간 제한, 능력 선택을 통해 점진적인 성장과 전략적인 플레이를 제공합니다.

## Game Description

Shadow Core Defense는  
2D 탑다운 디펜스 + 액션 + 로그라이크 성장 요소를 결합한 게임입니다.

플레이어는 라운드 기반 전투에서 생존하며,  
중앙의 코어를 보호하고 보스를 처치해야 합니다.

---

## Game Goal

플레이어는 다음 조건을 동시에 만족해야 합니다.

- 플레이어 생존
- 코어 보호
- 제한 시간 내 보스 처치

---

## Controls

이동 : 방향키 (↑ ↓ ← →)  
공격 : A  
대쉬 : D + 방향키  
아이템 사용 : 1 ~ 5  

스킬 사용 : Q / W / E  
사용 가능한 스킬이 자동으로 순차 배정됩니다  

패시브 스킬 : 게임 시작 시 자동 적용 (인게임 표시 : P)

설정 : ESC  
상태 확인 : Tab  

---

## Game Flow

라운드 시작  
→ 적 처치  
→ 보스 등장 (10라운드마다)  
→ 클리어 시 어빌리티 선택  

현재 최대 30라운드까지 진행됩니다.

---

## Defeat Conditions

- 플레이어 사망
- 코어 파괴
- 제한 시간 초과

---

## Enemy Types

Green Slime  
근접 공격 / 플레이어 공격

Blue Slime  
원거리 공격 / 플레이어 공격

Magma Slime  
근접 공격 / 코어 공격

---

## Boss Patterns

현재 구현된 보스 패턴은 다음과 같습니다.

- 슬라임 소환
- 순간이동
- 광역 공격

---

## Systems

Character System  
캐릭터 장착, 해체, 정보 표시 기능을 제공합니다.  
캐릭터를 장착하지 않으면 게임에 진입할 수 없습니다.  

캐릭터 창에서 스킬 아이콘에 마우스를 올리면  
해당 스킬 정보를 확인할 수 있습니다.

---

Inventory & Item System  
상점에서 아이템을 구매한 후 인벤토리에 장착하여 사용합니다.  

현재 구현된 아이템  
- HP 포션  
- MP 포션  

원활한 플레이를 위해 MP 포션 사용을 권장합니다.

---

Rune System  
플레이 보상으로 획득한 재료를 사용하여 룬을 제작할 수 있습니다.  
룬 장착 시 인게임 능력치에 적용됩니다.

---

Shop System  
상점에서 아이템을 구매하고 인벤토리와 연결되는 구조입니다.

---

UI System  
Stack 기반으로 UI를 관리합니다.  

ESC 입력 시 설정창이 활성화되며,  
Tab 입력 시 플레이어 상태를 확인할 수 있습니다.

---

## Note

현재 테스트 버전입니다.  
최대 30라운드까지 플레이 가능합니다.  
플레이어 스킬은 마나를 소모합니다.
